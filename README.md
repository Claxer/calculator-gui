# Calculator GUI

## Description

A simple calculator application with a graphical user interface (GUI) built using Python and Tkinter. It allows users to perform basic arithmetic operations through clickable buttons.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Error handling for invalid expressions
- Simple and easy-to-use graphical interface

## Technologies Used

- Python 3
- Tkinter

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project in your preferred Python IDE or editor.
4. Run `main.py`.
